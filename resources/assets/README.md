# Локальные ассеты

Каталог содержит очищенные копии ассетов из handoff. `docs/handoff` в git нет, поэтому
именно эти файлы — источник для сборки и тестов.

## Состав

| Каталог | Содержимое |
|---|---|
| `icons/products` | 29 товарных иконок (`apples.svg`, `carrot.svg`, …) |
| `ui-icons` | 35 интерфейсных иконок (`arrow-left.svg`, `vk.svg`, …) |
| `logo` | контурные логотипы для тёмного и светлого фона |
| `favicon` | SVG/PNG-favicon, `apple-touch-icon`, maskable-иконки, `site.webmanifest` |

## Команды

```bash
npm run assets:sync   # забрать ассеты из docs/handoff/03-assets и очистить SVG
npm run icons:build   # собрать Blade-партиалы, спрайт, логотипы и favicon в public/
```

`assets:sync` — локальная команда: без handoff она завершается ошибкой. Путь к handoff можно
переопределить переменной окружения `HANDOFF_DIR`. Результат `assets:sync` коммитится.

`icons:build` выполняется автоматически перед `npm run dev` (`predev`) и перед
`npm run build`, поэтому `composer dev` на чистом клоне сразу получает партиалы и спрайт.
Сгенерированные файлы тоже коммитятся; повторный запуск не меняет их содержимое.

## Правила

- Опубликованные SVG не должны содержать C2PA, `<metadata>` и посторонние `xmlns:*`
  (`xmlns:xlink` допустим). Это проверяет сборка.
- Варианты `on-disc` в рабочие поверхности не попадают: кремовый кружок рисуется
  разметкой или CSS. В `icons/products` таких файлов нет.
- Товарные иконки выводятся inline через `<x-product-icon name="…" />`, UI-иконки — одним
  спрайтом через `<x-ui-icon name="…" />`.
