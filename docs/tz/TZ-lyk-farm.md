## 2. Объём работ (MVP)

### 2.1 Входит

- **Главная страница** в двух версиях:
  - десктоп от 1200 px (эталон 1440×900), четыре сезона;
  - телефон 360–430 px (эталон 390), четыре сезона.
- **Колесо года** на десктопе с четырьмя сезонами, кольцом месяцев, иконками товаров, интерактивом (клик/drag/клавиатура).
- **Каталог** сезона: карточки (десктоп, до 8) и плитки (телефон, до 9) с ценами, статусами, фасовкой, иллюстрациями.
- **Карточка товара** (десктоп-модалка) и **шторка товара** (телефон) со всеми состояниями.
- **Меню** (десктоп-панель / мобильное на весь экран).
- **Заглушки разделов**: `/about`, `/preorder`, `/how-to-order`, `/contacts` — один компонент (заголовок + текст + кнопка «Назад»).
- **Состояния**: загрузка (скелетоны), ошибка сети, пустой сезон, пустой фильтр, 4 статуса наличия.
- **Контент**: четыре сезона на заглушках дизайнера v1.2 (`seasons-content.md`), заказчик меняет тексты на сайте (§10.3).
- **SEO-минимум** (см. §16.1): контент в HTML отдаёт Blade.
- **Аналитика**: опциональная Яндекс.Метрика по `YANDEX_METRIKA_ID`.

### 2.2 Не входит

Внутренние страницы (только заглушки), форма обратной связи, «Отложить» / избранное / корзина, счётчик количества, SEO сверх базового минимума, CMS и админка, оплата, планшетный макет, Figma-файл, письма, тёмная тема, мультиязычность. Аналитика — только опциональная Яндекс.Метрика по ID; без ID не подключается.

## 3. Продукт и контент (решения по вопросам В1–В12)

| № | Тема | Решение |
|---|---|---|
| В1, В10 | «Отложить для меня» | **Не делаем совсем.** Убираем кнопку «Отложить» на всех поверхностях, счётчик «− 1 +», бейдж на FAB, состояния `max/loading/success/error` для отложенного и полёт иллюстрации. Карточка товара становится информационной |
| В2 | Круглая кнопка (FAB) | **Оставить заглушкой**, только на телефоне, без бейджа. Клик показывает короткий тост «Скоро» (`aria-live="polite"`), никуда не ведёт. Позже заменяется реальным действием |
| В3 | Каталог по сезонам | **Мок-данные.** В MVP — сидеры и мок-каталог, админки нет. Модель данных сразу проектируется под будущую админку |
| В4 | Тексты зимы/весны/лета | **Заглушки.** Дизайнер сдал три сезона с текстами-заглушками (v1.2, `seasons-content.md` / `.csv`), заказчик меняет их позже в готовом сайте. Разработка переносит заглушки в сидеры |
| В5 | Весовые товары | **По-разному.** У товара есть `saleUnit` (`piece` / `kg`), `step` (1 или 0,5), `priceUnit` (`₽` / `₽/кг`). Развесные овощи — кг, шаг 1 кг; упаковки/банки/пучки — штуки. В MVP счётчика нет, поля хранятся на будущее |
| В6 | «Нет в наличии» | **Убирать из сеток.** Товары со статусом `out` не попадают в сетки, плитки, колесо и счётчики. Прямая ссылка `?product=…` всё равно открывает карточку с состоянием «нет в наличии», чтобы ссылка не была битой |
| В7 | Меню и контакты | **Минимальное меню, контакты — заглушки.** Шапка: «О семье», «Сезоны», «Как заказать»; меню — те же плюс «Предзаказ», «Контакты». Контакты и соцсети — заглушки |
| В8 | «Предзаказ →» и плитка «скоро» | **На заглушку** `/preorder` (текст-заглушка + кнопка «Назад»). Туда же ведут «ПРЕДЗАКАЗ →», плитка «скоро» и кнопка предзаказа в карточке |
| В9 | Разделы (таксономия) | **Категории через админку, сейчас мок.** Три категории из дизайна: Овощи, Сад, Травы. Категория — отдельная сущность с цветом, формой значка и иконкой |
| В11 | Формат цены | **«650 ₽» и «650 ₽/кг».** Целые рубли, неразрывный пробел в тысячах, без «от», скидок и старой цены |
| В12 | Аналитика | **Яндекс.Метрика**, опционально через `YANDEX_METRIKA_ID` в `.env`. Нет ID — счётчик не грузится, cookie-баннер не показывается. Google Analytics и прочие не подключаем |

### 5.2 Токены и палитра

- Фоны сезонов:
  - осень `#2F4A3A → #22352A`;
  - зима `#2B3E44 → #1F2E33`;
  - весна `#3A5A47 → #2F4A3A`;
  - лето `#44583A → #2D3E2A`.
- Кремовый кружок активного сектора колеса `#EADFC8`, неактивного — Parchment `#F3EBDB`.

Это единицы `viewBox` колеса 700, а не пиксели экрана: масштабируются вместе с колесом. Токены `--wheel-disc-active: calc(var(--wheel) * 50 / 700)`, `--wheel-disc-inactive: calc(var(--wheel) * 40 / 700)`, `--wheel-icon-ratio: .76`, `--wheel-icon-hover-scale: 1.1`, `--wheel-icon-hover-ring`.

- Радиусы: чипы фильтра 16 px, факты 14 px.
- Фокус — два токена: тёмный и светлый (`focus-on-dark` / `focus-on-light`); кольцо повторяет арку.

- Минимум текста интерфейса — 12 px. Исключения: «СЕМЕЙНАЯ ФЕРМА» в логотипе (10.5) и подпись над полем (11 px, дублирует назначение поля).

## 6. Адаптив и сетка

- **Брейкпоинт 1200 px** по ширине вьюпорта. Ниже — мобильная версия, выше — десктоп.
- **768–1199:** мобильная версия в контейнере `max-width: 520px` по центру; фон сезона (градиент) на всю ширину.
- **Десктоп 1200–1439:** колесо и колонка сжимаются формулами (кадры 1200×680, 1280×720).
- **Мобильный диапазон:** 360–430, эталон 390. 320 не поддерживаем, но не ломаем (плитки 3 колонки, чипы скроллятся).
- **Десктоп-сетка:** контент не шире 1440, шире — фон тянется, контент центрируется (Д13). Поля: слева `clamp(32px, 4.2vw, 60px)`, зазор колесо—колонка `clamp(36px, 3.5vw, 50px)`, справа `clamp(32px, 2.8vw, 40px)`.
- **Колесо:** `clamp(480px, min(47vw, 100vh − 170px), 680px)`.
- **Правая колонка:** `minmax(0, 610px)`, 4 колонки, `gap: 14px 12px`.
- **H1:** `clamp(36px, 4.9vh, 44px)`; иконка карточки `clamp(50px, 6.9vh, 62px)`.
- **Плитки (телефон):** высота `clamp(112px, (100dvh − 310px) / 3, 146px)`; иконка = 42 % высоты плитки.
- **Особые случаи:** альбомная ориентация — обычная прокрутка; zoom 200 % / крупный шрифт — высоты через `min-height`; `100dvh`; при нехватке места — прокрутка страницы.
- **Низкий десктоп (принято в v1.2 по предложению дизайнера):** «один экран» — цель, а не ограничение. Если контент не помещается по высоте (1200×680 и 1280×720 со статусами «осталось N»/«предзаказ», полоса «Дальше — …» уходит ниже фолда), страница прокручивается вертикально. Ничего не сжимаем сверх формул §6 и не обрезаем; минимальный размер окна для десктопа — 1200×640.

## 7. Главная — десктоп

### 7.1 Колесо года

- Активный сезон **всегда справа**; угол поворота группы = `−(i−1)·90°`, где i: лето(0), осень(1), зима(2), весна(3).
- Вращается вся группа: сектора + кольцо месяцев + засечки. Центр (логотип, «Колесо года», текущий год) не вращается.
- Подписи месяцев с итоговым углом 90–270° дополнительно поворачиваются на 180° (переворот по целевому углу, один раз в конце — Д4). Названия сезонов и иконки всегда стоят прямо (контр-поворот).
- Маркер текущего месяца: подпись Honey 14 px 800 + точка Honey 8 px за внешним кольцом.
- Подпись сектора — поле сезона `sub` (`УРОЖАЙ`, `ЗАПАСЫ`, `ЗЕЛЕНЬ`, `ЯГОДЫ`), не длиннее 7 знаков (Д25).
- Иконки в секторе: активный — до 4, неактивный — до 3, по флагу `showOnWheel` в порядке `wheelOrder`, если поля нет — по `sortOrder` (Д27). Всегда на кремовом кружке (активный `#EADFC8`, неактивный Parchment); кружок рисует код, файлы `*-on-disc.svg` не используются.
- Размеры и прозрачность иконок (v1.2): кружок активного сектора 50 ед., неактивного 40 ед., иконка 76 % диаметра (38 / 30,4 ед.); прозрачность группы активной `1`, неактивной `.7`, неактивной при наведении `.9`. Всё в единицах `viewBox` колеса 700 и масштабируется вместе с ним; на 1440×900 это ≈48/39 px. HTML-кружки поверх колеса — через токены `--wheel-disc-active` / `--wheel-disc-inactive`.
- Пустой сезон: подпись сектора «ПОКА ПУСТО», иконок нет.
- Ввод: клик по сектору, drag, ←/→, Home/End. Инерции нет, только доводка 700 ms spring. По кругу, без границ. Горизонтальный жест тачпада над колесом не перехватываем.
- Hover сектора — заливка Parchment 6 % → 14 %, иконки `.7` → `.9`; hover иконки — кружок и иконка `scale 1.1` (150 ms), иконка становится `1`, вокруг кружка кольцо Honey 2 ед. (радиус = кружок/2 + 3 ед.).
- Tooltip: плашка Ink, 12.5 px 700, над иконкой, отступ 12 px, хвостик 6 px, задержка 300 ms, сдвиг внутрь у края колеса. Только мышь: на тач-экране tooltip и кольца нет, тап по иконке = тап по сектору.
- Фокус: обводка Honey 3 px по форме сектора с отступом 6 px; фокус только между секторами, иконки в порядок фокуса не входят и отдельно не кликаются.
- Доступность названий без мыши: у сектора `aria-label` со списком товаров (Д9).

### 7.2 Каталог сезона (правая колонка)

- H1 сезона, лид под ним (лид до 600 px).
- Сетка до 8 карточек (2×4). В сетку и карусель попадают только товары с `showOnDesktop = true`: в сезоне может быть 9 товаров, девятый показываем только на телефоне. Больше 8 видимых — карусель по 4 (стрелки, полоса прогресса). Меньше 8 — сетка не растягивается, пустые места не заполняем.
- Карточка: иллюстрация, надзаголовок (раздел · сбор), название (до 2 строк + многоточие), фасовка (1 строка), цена, статус.
- Полоса «Дальше — …» со следующим сезоном и его иконкой из поля сезона `teaserIcon` (не вычисляется из колеса) на кружке Parchment. Цепочка: осень → зима → весна → лето → осень.
- Фильтр на десктопе не нужен (8 карточек читаются целиком).
- Если из-за статусов «осталось N»/«предзаказ» полоса «Дальше — …» не помещается на низком экране (1200×680, 1280×720), страница прокручивается вертикально (§6), шаблон не сжимаем.

### 7.3 Окно товара

- Ширина 520, арка 260/260/8/8, отступы по бокам 52 px, иллюстрация 120 px на кружке, надзаголовок 12 px Brick, название 34 px, текст 15/1.6, факты, цена, кнопка во всю ширину.
- Крестик 44×44, Parchment, в правом верхнем углу прямоугольника окна (вне арки), тень `0 6px 16px rgba(0,0,0,.25)` (Д16).
- `max-height: calc(100vh − 64px)`; шапка (иллюстрация, название) и низ (цена, кнопка) закреплены, прокручивается только описание; снизу градиент 40 px.
- Overlay `rgba(15,22,18,.6)`, клик мимо закрывает.
- Статусы: «осталось N» — бейдж под ценой; «предзаказ» — бейдж + золотая кнопка «Записаться на предзаказ» → `/preorder`; «нет в наличии» — иллюстрация приглушена, вместо кнопки пояснение «закончилась… снова будет в …».
- «Отложить» и счётчик количества — **не делаем** (В1, В10). Для `in_stock`/`few` CTA нет.

## 8. Главная — мобильная версия

### 8.1 Лента сезонов

- Свайп сезонов по кругу (после зимы — весна, перед весной — зима). Параллакс + доводка.
- Точки сезонов: порядок всегда весна, лето, осень, зима (как в году), а не порядок колеса.
- Подсказки соседних сезонов по краям («‹ Лето» / «Зима ›») — на всех сезонах.
- Подпись под названием сезона: у текущего — текущий месяц («ОКТЯБРЬ»), у остальных — диапазон месяцев («ДЕК–ФЕВ»); рядом число продуктов, посчитанное по всем товарам сезона («ДЕК–ФЕВ · 9 ПРОДУКТОВ»).
- Свайп сезона не начинается в первых ~20 px от левого края (iOS-жест «назад», Д14).

### 8.2 Плитки

- Сетка 3×3 (до 9 плиток), на телефоне показываем все товары сезона, включая `showOnDesktop = false`. Больше 9 — вертикальный скролл. Меньше 9 — сетка не растягивается; при наличии предзаказа последняя плитка «скоро» (в заглушках — только у весны: «скоро: первая клубника · предзаказ →»).
- Плитка: название (2 строки), фасовка (1 строка), цена, статус.
- Длинные названия — 2 строки + многоточие; шрифт плитки 13/12 px не уменьшается.
- Чипы фильтра: 4 шт., зона нажатия 32 px + невидимое расширение до 44 px, радиус 16 px.
- Фильтр: при выборе категории лишние плитки приглушаются до `.55`, `aria-disabled="true"`, `pointer-events: none` (Д5). Пустой фильтр — состояние «Трав этой осенью уже нет» + кнопка «Показать все».

### 8.3 Шторка товара

- Арка `50vw 50vw 0 0`; `max-height: calc(100dvh − 40px)`; прокручивается только описание, низ (цена, кнопка) закреплён.
- Жест закрытия: тянем везде, но только когда внутренний скролл наверху; горизонтальный жест фактов имеет приоритет (Д10).
- Факты — одна строка с горизонтальной прокруткой и затуханием справа.
- Статусы — как в десктопном окне (§7.3). Надзаголовок всегда «раздел · сбор …», статус — бейджем у цены.

### 8.4 FAB

- Только телефон, визуальная заглушка без бейджа. Клик — тост «Скоро» (`aria-live="polite"`), никуда не ведёт.
- Привязка к контейнеру 520 px (не к вьюпорту) на 768–1199 (Д20).
- `bottom: calc(18px + env(safe-area-inset-bottom))`; резерв снизу сетки 80 px, чтобы не закрывал последнюю плитку (Д6).
- Подсказки краёв — тоже к контейнеру, а не к вьюпорту.

## 9. Состояния интерфейса

### 9.1 Загрузка, ошибка, пустота

- Скелетоны при ответе дольше 300 ms, минимум показа 400 ms; колесо рисуется сразу без иконок (не зависит от данных).
- Ошибка сети — отдельный экран с кнопкой «Повторить».
- Пустой сезон — состояние с текстом из поля сезона `emptyText` (заглушки — `seasons-content.md`) и кнопкой к ближайшему сезону с товарами; подпись сектора колеса — «ПОКА ПУСТО».
- Пустой фильтр — состояние «…уже нет» + «Показать все».
- При возврате из bfcache загрузку/анимацию не повторяем.

### 9.2 Статусы наличия

| Статус | Карточка (десктоп) | Плитка (телефон) | Окно / шторка |
|---|---|---|---|
| Есть | ничего | ничего | ничего |
| Осталось N | бейдж «осталось N» под ценой | «380 ₽ · ост. N» (few-text) | бейдж у цены |
| Предзаказ | бейдж «предзаказ» под ценой | вместо цены «ПРЕДЗАКАЗ» (pre-text) | бейдж + кнопка «Записаться на предзаказ» |
| Нет в наличии | иллюстрация приглушена, вместо цены «нет в наличии» | то же | цена приглушена, вместо кнопки пояснение |

- Под ценой — фиксированная строка высотой в одну строку, чтобы baseline карточек в ряду не ломался (Д7).
- «Нет в наличии» в сетки/плитки/колесо/счётчики не попадает (В6).

## 10. Данные и модель

### 10.1 Товар

```ts
interface Product {
  slug: string;                 // для URL
  name: string;                 // «Антоновка»
  storyTitle: string;           // «Антоновка с дедушкиной яблони»

  step: number;                 // 1 или 0.5 (на будущее, в MVP счётчика нет)
```

### 10.2 Категории и сезоны

- `categories`: `slug`, `name`, `color`, `shape` (`circle` / `diamond` / `leaf`), `icon`, `sortOrder`.
- `seasons`: `slug`, `name`, `sub` (подпись сектора колеса, ≤ 7 знаков), `h1`, `lead`, `nextLabel`, `teaserIcon` (иконка полосы «Дальше — …»), `mobileTitle`, `mobileSub` (диапазон месяцев, например «ДЕК–ФЕВ»; для текущего сезона подставляется текущий месяц — «ОКТЯБРЬ»), `emptyText`, `bgFrom`, `bgTo`, `sortOrder`.
- Товар и сезон связаны многие-ко-многим: совпадающие по названию, фасовке и цене товары разных сезонов — одна запись с несколькими сезонами (в заглушках: варенье смородиновое, иван-чай, лист смородины). Разные товары с похожим названием (мята сушёная и свежая) — отдельные записи.
- Всё редактируется сидерами; будущая админка меняет те же поля без миграций.
- Значения текстов и состав товаров — из `docs/handoff/seasons-content.md` / `.csv` (§10.3).

### 10.3 Мок-данные

Источник — `docs/handoff/seasons-content.md` / `.csv` (v1.2): тексты сезонов и полные таблицы товаров. Всё содержимое — заглушки, заказчик меняет на сайте.

- Осень — 9 товаров (эталон, данные из `05-html-source/v2/lib.js`, `SEASONS.autumn`).
- Зима — 9 товаров (9-я плитка «Мята сушёная» только на телефоне, `showOnDesktop = false`), весна — 8, лето — 9 (9-я плитка «Зверобой» только на телефоне). Все товары — из 29 готовых иконок.
- На колесе — по 4 товара с `showOnWheel` в порядке `wheelOrder`; неактивный сектор показывает первые 3.
- Предзаказ: «Новогодний чайный набор» (зима), «Рассада томатов» (весна), «Ранние яблоки» (лето). «Осталось 3»: варенье смородиновое (зима и весна), клубника (лето).
- Плитка «скоро» — только у весны (8 товаров): «скоро: первая клубника · предзаказ →», ведёт на `/preorder`.
- Для проверки состояния «нет в наличии» в сидер добавляется один товар со статусом `out` (в таблице дизайнера его нет): в сетки, плитки, колесо и счётчики он не попадает, доступен только по прямой ссылке `?product=…`.
- Тексты сезонов (H1, лид, «Дальше — …», подписи, текст пустого сезона) — заглушки дизайнера из `seasons-content.md`, без выдуманных фактов о ферме; `teaserIcon` и `sub` — оттуда же.
- Цены/фасовки — заглушечные, но правдоподобные: «1 200 ₽», «150 ₽/кг» (`priceUnit: rub_per_kg` у весовых: ранние яблоки, кабачки).

## 11. Форматы отображения

- **Вес:** «5 кг», «0,5 кг», «2–4 кг» (десятичная запятая, короткое тире без пробелов). Тара словами впереди: «ящик 5 кг», «банка 0,5 л»; штучные весовые — «1 шт, 2–4 кг». Фасовка в заглушках: «пучок», «стакан 0,5 л», «лоток 0,5 кг», «коробка, 3 × 50 г», «1 шт», «100 г», «30 г».
- **Единица продажи:** `kg` — развесные (яблоки, кабачки, клубника), `piece` — банки, пучки, наборы, упаковки; `step` (1 или 0,5) хранится на будущее, в MVP счётчика нет и на интерфейс не влияет.
- **Цена:** «650 ₽» / «650 ₽/кг», целые рубли, неразрывный пробел в тысячах («1 080 ₽»), без «от» и скидок.
- **Склонения:** «1 продукт / 2 продукта / 5 продуктов» через `Intl.PluralRules('ru')`.
- **Даты:** в тексте «2–10 октября», «суббота, 14 ноября»; в таблицах «14.11.2026».
- **Телефон:** «+7 900 000-00-00».

## 12. URL, история и слои

- Ссылки: `/?season=winter`, `/?season=autumn&product=antonovka`, `?season=…&cat=…&product=…`.
- Стартовый сезон — по текущему месяцу (дек–фев зима, мар–май весна, июн–авг лето, сен–ноя осень); если пуст — всё равно открываем с пустым состоянием и кнопкой к ближайшему сезону.
- Сезон и фильтр — в URL; в localStorage не сохраняем.

- Слои: одновременно один. z: шапка 10, FAB 20, затемнение 30, окно/шторка 31, меню 40, tooltip 50.
- Скролл блокируется всегда при открытом слое (обе версии).
- Возврат фокуса после закрытия — на карточку-источник; если её нет — на заголовок сезона (`tabindex="-1"`).

## 13. Доступность

- Контраст: текстовые пары ≥ 4.5:1 (крупный ≥ 3:1), границы/фокус ≥ 3:1 — на каждом сезоне.
- Различие не только цветом: значок раздела — формой (круг/ромб/лист), статусы — текстом и значком.
- Зоны нажатия: точки сезонов 24×44, чипы 32 + расширение до 44, крестик 44×44, «ПРЕДЗАКАЗ →» `padding: 12px 0`.
- Клавиатура: колесо, карточки, окно, шторка, меню достижимы; фокус виден; ловушек нет.
- Скринридер: `tablist` у колеса, `dialog` у слоёв, `aria-live` при смене сезона, скрытая кнопка закрытия шторки.
- Колесо: фокус только на секторах, у сектора `aria-label` со списком товаров; иконки отдельно не фокусируются и не кликаются. Tooltip и увеличение иконки (`scale 1.1`, кольцо Honey) — только для мыши; на тач-экране тап по иконке = тап по сектору.
- Zoom 200 %, системный шрифт +30 %: ничего не обрезается, появляется прокрутка.
- `prefers-reduced-motion` (§14).

## 14. Интерактив и анимации

Формат описания: **событие → что происходит → длительность и кривая**. Размеры и состояния элементов — §7, §8, §13; здесь — тайминги, кривые, реализация и правила движения.

### 14.1 Токены и общие правила

| Токен | Значение | Для чего |
|---|---|---|
| `--dur-fast` | 150 ms | наведение, подсветка, фокус |
| `--dur-base` | 250 ms | кнопки, чипы, точки, плитки |
| `--dur-slow` | 400 ms | меню, окно, шторка, смена сезона на телефоне |
| `--dur-wheel` | 700 ms | поворот колеса |
| `--dur-stagger` | 60 ms | шаг появления карточек |
| `--ease-standard` | `cubic-bezier(0.2, 0, 0, 1)` | почти всё |
| `--ease-exit` | `cubic-bezier(0.4, 0, 1, 1)` | закрытие, исчезновение |
| `--ease-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | доводка колеса, возврат шторки |

- Анимируем только `transform`, `opacity` (иногда `background-color`, `border-color`); `width`, `height`, `top`, `left` не анимируем.
- `:hover` — только внутри `@media (hover: hover)`; фокус — `:focus-visible`, кольцо Honey.
- Состояния всех контролов: наведение — светлее/подложка (иногда подъём 2 px); нажатие — темнее, сжатие до 94–98 %; фокус — кольцо Honey 2 px, отступ 3 px; неактивное — `opacity .38`, `not-allowed`, без реакции (`:disabled` / `aria-disabled="true"`). Нарисовано в `02-ui-kit/1-uikit-base`.

### 14.2 Загрузка страницы

1. Фон и шапка видны сразу, без анимации.
2. Колесо проявляется и доворачивается на 20° к текущему сезону — 700 ms, `--ease-spring`.
3. H1 поднимается на 12 px и проявляется — 400 ms, задержка 150 ms.
4. Карточки — по одной: подъём 12 px + opacity, 250 ms на карточку, шаг 60 ms.
5. Телефон: колеса нет, плитки появляются волной слева направо и сверху вниз, шаг 40 ms.

Анимацию входа показываем только при первом заходе в сессию (флаг в `sessionStorage`), чтобы возврат «назад» не проигрывал её заново (bfcache, §9.1).

### 14.3 Шапка и меню

- **Кнопка меню** (круг 56 px, на телефоне 44 px): hover — рамка Flax → Honey + подложка `rgba(243,235,219,.1)` (150 ms); нажатие — сжатие до 94 %; бургер ↔ крестик за 250 ms (средняя линия исчезает, крайние поворачиваются на ±45°). `aria-label="Открыть меню" / "Закрыть меню"`, `aria-expanded`.
- **Навигация в шапке:** hover — opacity .8 → 1, цвет Honey, подчёркивание 1.5 px растёт слева направо (150 ms); у текущего раздела подчёркивание видно постоянно.
- **Меню:** десктоп — панель 430 px выезжает слева, затемнение `rgba(15,22,18,.5)`; телефон — на весь экран, Forest, въезд сверху на 16 px. 400 ms, standard. Пункты появляются по одному (сдвиг 16 px + проявление, шаг 50 ms); hover пункта — сдвиг 8 px вправо и Honey. Закрытие — 250 ms, exit, пункты гаснут сразу; закрывается крестиком, кликом по затемнению, Esc, на телефоне — свайпом влево. Скролл заблокирован, фокус-ловушка, после закрытия фокус — на кнопку меню.

### 14.4 Колесо года

- Смена сезона синхронно с поворотом (700 ms, spring): новый сектор заливается Parchment, текст Deep Pine, кружки 40 → 50 ед., opacity `.7` → `1`, цвет Parchment → `#EADFC8` (400 ms), прежний сектор гаснет. Подписи месяцев не переворачиваются «вверх ногами» — текст компенсируется обратным поворотом (§7.1).
- Колонка справа: старые карточки уходят вниз на 12 px и тают (250 ms, exit, все сразу), новые поднимаются по одной (250 ms, шаг 60 ms); H1 и лид — opacity 1 → 0 → 1, 2 × 200 ms; полоса «Дальше — …» меняет сезон.
- Клик по сектору и клавиатура (←/→, Home/End) — доворот до сезона 700 ms spring; drag — колесо идёт за курсором без задержки, при перетаскивании `transition` отключается.
- Реализация: SVG, `transform: rotate()` на группе секторов, `transform-origin` в центре, текущий угол — в состоянии.
- Доступность: `role="tablist" aria-label="Сезоны"`, сектора `role="tab" aria-selected`, правая колонка — `role="tabpanel"`; при смене объявляем через `aria-live="polite"`: «Осень, 8 продуктов».

### 14.5 Карточки, плитки и окно товара

- Карточка: hover — арка поднимается на 6 px, тень `--shadow-card-hover`, иллюстрация `scale 1.08` и одно покачивание ±4° (250 ms); нажатие — сжатие до 98 %; фокус — кольцо Honey по форме арки.
- Открытие окна — FLIP: окно вырастает из нажатой карточки к центру экрана, страница затемняется (400 ms, standard). Закрытие — 250 ms, exit, окно уходит обратно в карточку.
- Плитка (телефон): касание — сжатие до 96 %; при отпускании — обводка Honey 2 px (offset 3 px) и открытие шторки (400 ms).
- Шторка: затемнение до `rgba(15,22,18,.6)`, подъём снизу — 400 ms, standard; тянем за любое место, но только когда внутренний скролл наверху (§8.3), затемнение слабеет пропорционально; закрытие после ⅓ высоты или быстрого смаха вниз — 250 ms, exit, иначе возврат пружинкой (400 ms, spring).
- Чипы фильтра: заливка Parchment, текст Deep Pine (250 ms); лишние плитки приглушаются без перестройки сетки (§8.2).

### 14.6 Лента сезонов на телефоне

- Палец ведёт — лента идёт 1:1, фон перетекает в цвет соседнего сезона пропорционально сдвигу; параллакс: название сезона уезжает в 1.3 раза быстрее сетки.
- Отпускание после ¼ ширины экрана или флика > 0.5 px/ms — листание на соседний сезон (400 ms, standard), иначе возврат пружинкой (400 ms, spring).
- Активная точка растягивается в полоску 22 × 8 px Honey, прежняя сжимается (250 ms); новые плитки — волной, шаг 40 ms.
- Подсказки краёв при первом визите один раз качаются в сторону свайпа на 6 px (600 ms).
- Горизонтальный свайп начинаем, только если сдвиг по X больше, чем по Y, после первых 10 px (`touch-action: pan-y` на ленте), — вертикальный скролл страницы не ломается. Тап по точке тоже переключает сезон (кнопки с `aria-label`).

### 14.7 FAB и тост

FAB — заглушка (§8.4): нажатие сжимает круг до 94 %, клик показывает тост «Скоро» (`aria-live="polite"`, проявление 150 ms), никуда не ведёт. Бейджа-счётчика, формы и подписи «Написать нам» нет: ни корзины, ни формы в MVP нет (В1, В2).

### 14.8 Reduced motion

`prefers-reduced-motion: reduce` — сдвигов, поворотов, масштабирования и полёта иллюстрации нет; остаётся только opacity 150 ms: колесо меняет положение мгновенно, окно/шторка/меню и карточки проявляются.

## 15. Технические требования

### 15.1 Стек

- PHP 8.5, Laravel 13; Node 26, Vite; Vue 3 (**только Options API**, Composition API не используем) + TypeScript strict + zod; PostgreSQL 15.2.
- Монолит: фронт в `resources/js`, шаблоны Blade отдают страницу.
- Пакеты: `vasichmen/laravel-foundation`, `vasichmen/laravel-handbooks` (поддерживаются заказчиком, правки допустимы отдельной задачей).

### 15.2 Рендеринг: Blade + Vue-острова

- SSR не делаем. Контент отдаёт Blade, интерактив — независимые Vue-острова; единого корневого экземпляра нет.
- Правило разделения: текст, который должен попасть в индекс, рисует Blade; блок, бесполезный без клика, — остров.

| Блок | Кто рисует |
|---|---|
| Шапка, меню, подвал | Blade |
| `h1`, лид, тексты сезонов | Blade |
| Сетка каталога, карточки, цены | Blade |
| Колесо сезонов | остров |
| Переключатель сезонов | Blade (ссылки `?season=`), остров — если без перезагрузки |
| Корзина / предзаказ | корзины нет (В1); кнопка «Записаться на предзаказ» — ссылка на `/preorder` из Blade |
| FAQ | Blade + `<details>` |
| Модалки, карусели, тост FAB | остров |

- Один entry-point `resources/js/app.ts` с реестром `{ 'season-wheel': SeasonWheel, ... }`; ищет `[data-island]`, монтирует из реестра, неизвестное имя — `console.warn` и пропуск.
- Контейнер острова: `<div data-island="season-wheel" data-props='@json($props)'></div>`. Данные — пропсами из HTML, не запросом в `mounted()`.
- Общее состояние между островами — модуль-стор (`reactive`) как синглтон. Отдельные бандлы на каждый остров не делаем.
- `vue-router` не заводим; переходы — `<a href>` и маршруты Laravel.
- Острова ниже фолда — лениво через `IntersectionObserver` + `import()`.
- Ограничения: `mount()` затирает содержимое узла (SEO-контент — вне контейнеров); гидратации нет; острова не вкладываются; пустому контейнеру — `min-height` (без CLS); большой JSON — через `<script type="application/json">` или `fetch`.
- HTTP-клиент — **нативный `fetch`** (Т2). `axios` и сторонние обёртки (`ofetch`, `ky`) не подключаем: в MVP острова получают данные пропсами из HTML, клиент нужен только для будущих клиентских запросов.

### 15.3 База

- Контейнер PostgreSQL запущен; БД `lyk-farm` создана.
- `.env`:

```env

DB_HOST=127.0.0.1
DB_PORT=5432
DB_DATABASE=lyk-farm
DB_USERNAME=ippu
DB_PASSWORD=ippu
```

### 15.4 Локальный запуск

## 16. SEO

### 16.1 Входит (базовый минимум)

- `title`, `description`, `canonical` — из Blade, на каждую страницу.
- Open Graph и Twitter Card — из Blade (превью-боты JS не выполняют).
- Семантика: один `h1`, иерархия заголовков, `<nav>`, `<main>`, `<footer>`, `<details>` у FAQ.
- Ссылки — настоящие `<a href>`; роутинг серверный.
- Текст текстом: `h1`, названия, цены — не внутри SVG-арта и не картинками.
- JSON-LD: `Organization`/`LocalBusiness` на главной; `Product` + `Offer` — заготовка.
- Корректные HTTP-статусы: 404/410, 301 на редиректах; без SPA-фолбэка с 200.
- `robots.txt` и `sitemap.xml` — генерируются в Laravel.
- Производительность: preload LCP, `fetchpriority="high"`, AVIF/WebP + `srcset`, размеры изображений, `font-display: swap` + preload шрифтов, критический CSS.
- Проверка: `curl -A "Googlebot"` отдаёт контент в HTML.

### 16.2 Не входит

Контентная оптимизация (семантика, ключи), перелинковка, хлебные крошки, страницы категорий/тегов, мультиязычность и `hreflang`, посадочные/блог/отзывы, аналитика поиска, пререндер/SSR/dynamic rendering.

### 16.3 Точки роста

Метатеги — отдельный Blade-партиал с параметрами страницы; JSON-LD — partial на тип сущности; `sitemap.xml` собирается из тех же репозиториев.

## 21. Критерии приёмки

- Визуальная приёмка заказчиком «на глаз» по PNG @2x и токенам, без пиксельного допуска.
- Четыре сезона на двух размерах, переключение без перезагрузки, состояние в URL; контент сезонов — заглушки из `seasons-content.md` (§10.3).
- Колесо: иконки по правилу v1.2 (кружки 50/40 ед., иконка 76 %, opacity `.7` / `.9` / `1`), подпись сектора ≤ 7 знаков, на колесе по 4 товара сезона, неактивный сектор — первые 3.
- На десктопе в сетке только `showOnDesktop = true` (до 8 карточек), на телефоне — все (до 9 плиток), плитка «скоро» только у весны.
- Низкий десктоп 1200×680 / 1280×720: контент не обрезается, страница прокручивается.
- Клавиатура и скринридер: всё достижимо, фокус виден, ловушек нет, `aria-live` при смене сезона.
- Контраст на каждом сезоне (§13).
- `prefers-reduced-motion` — только прозрачность.
- Zoom 200 %, системный шрифт +30 % — ничего не обрезается.
- iPhone SE 375×667 и 375×553: сетка и чипы помещаются, FAB не закрывает контент.
- Нет ошибок в консоли, CLS < 0.1, LCP < 2.5 s на 4G.
- SEO-минимум виден в исходном HTML (§16.1).
- Все цвета, размеры и тайминги — из токенов, «магических» значений нет.
