# Сидеры каталога

Источники мок-контента:

- зима, весна, лето — `docs/handoff/seasons-content.md` и `seasons-content.csv`;
- осень — эталон `docs/handoff/05-html-source/v2/lib.js` (`SEASONS.autumn`, `PR`).

После переноса источником истины становятся сидеры: правки контента вносятся в
`ProductSeeder`, `SeasonSeeder` и `CategorySeeder`. Каталог идемпотентен — повторный
`php artisan db:seed` не создаёт дублей (товары ищутся по вычисленному slug, связи
синхронизируются через `sync()`).

## Слияние общих товаров

Товары, совпадающие по названию, фасовке и цене, хранятся одной записью с несколькими
сезонами. Сезонные отличия (место в сетке, флаги показа, порядок на колесе и период
сбора) живут в pivot-таблице `product_season`.

| Каноническое название | Сезоны |
|---|---|
| Сбор «Усадебный» | осень, зима |
| Яблочные чипсы | осень, зима |
| Слива сушёная | осень, зима |
| Варенье смородиновое | зима, весна |
| Иван-чай | зима, весна |
| Мята | осень, весна |
| Лист смородины | весна, лето |

«Мята» и «Мята сушёная» — разные записи: у них отличаются фасовка и цена.

## Формат периода сбора

Поле `harvest` хранит готовый фрагмент **без слова «сбор»**: `в мае`, `в июне`,
`2–10 октября`. Префикс «сбор » добавляет фронтенд при выводе — backend отдаёт сырое
значение и не занимается форматированием.
