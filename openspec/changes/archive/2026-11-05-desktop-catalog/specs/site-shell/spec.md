# Spec Delta

## MODIFIED Requirements

### Requirement: Главная страница доступна по корневому адресу
Система SHALL отвечать на `GET /` статусом 200 и HTML-документом с сезонным заголовком первого уровня, лидом и товарами выбранного сезона на русском языке.

#### Scenario: Открытие главной страницы
- **WHEN** клиент запрашивает `GET /`
- **THEN** ответ имеет статус 200 и тип `text/html`
- **AND** в HTML присутствуют заголовок первого уровня, лид и товары выбранного сезона

#### Scenario: Главная страница без JavaScript
- **WHEN** клиент запрашивает `GET /` и не выполняет клиентские скрипты
- **THEN** заголовок первого уровня, лид, названия товаров, цены и статусы присутствуют в исходном HTML

#### Scenario: Заголовок первого уровня один
- **WHEN** клиент запрашивает `GET /`
- **THEN** в документе ровно один заголовок первого уровня

#### Scenario: Смена сезона меняет содержимое главной
- **WHEN** клиент запрашивает `GET /?season=winter`
- **THEN** заголовок первого уровня, лид и товары относятся к зимнему сезону
