# client-islands Specification

## Purpose
Позволяет серверному HTML объявлять интерактивные блоки, которые клиентский скрипт монтирует по разметке, не заменяя серверный контент и не ломая страницу при ошибке в объявлении острова.

## Requirements

### Requirement: Остров монтируется по объявлению в разметке
Система SHALL находить на странице контейнеры с именем зарегистрированного острова и монтировать в них соответствующий интерактивный компонент.

#### Scenario: Монтирование зарегистрированного острова
- **WHEN** страница содержит контейнер с именем зарегистрированного острова
- **THEN** после загрузки клиентского скрипта внутри контейнера появляется интерактивный компонент

### Requirement: Данные острова передаются из HTML
Система SHALL передавать острову данные из атрибута контейнера в HTML, без отдельного запроса за этими данными при монтировании.

#### Scenario: Использование переданных данных
- **WHEN** контейнер острова содержит данные в разметке
- **THEN** смонтированный компонент отображает значения, совпадающие с переданными

### Requirement: Неизвестный остров не ломает страницу
Система SHALL пропускать контейнер с незарегистрированным именем острова, выводить предупреждение в консоль и продолжать работу остальной страницы.

#### Scenario: Незарегистрированное имя острова
- **WHEN** страница содержит контейнер с именем, отсутствующим в реестре островов
- **THEN** в консоли появляется предупреждение
- **AND** остальные острова и серверный контент страницы продолжают работать

### Requirement: Некорректные данные острова не ломают страницу
Система SHALL пропускать остров с некорректными данными в разметке, сообщать об ошибке в консоль и не прерывать выполнение остальных скриптов страницы.

#### Scenario: Некорректный JSON в данных острова
- **WHEN** контейнер острова содержит данные, которые не удаётся разобрать
- **THEN** остров не монтируется
- **AND** в консоли появляется сообщение об ошибке
- **AND** остальная страница остаётся работоспособной

### Requirement: Серверный контент вне острова сохраняется
Система SHALL монтировать остров только внутри его контейнера и MUST NOT изменять серверный HTML за пределами этого контейнера.

#### Scenario: Контент рядом с островом
- **WHEN** остров монтируется на странице с серверным текстом рядом с контейнером
- **THEN** серверный текст остаётся на странице без изменений
